# M&H HVAC website

Static site, no build step. Serve the folder (Netlify) or open `index.html` via a local server.

- `index.html` — homepage. The header/menu and footer between the `SHARED:CHROME` markers are copied into every other page.
- `assets/css/mh.css` — all site styles. `assets/js/site.js` — header, menu, fades, gallery filters + lightbox, form, van.
- `services/*/`, `service-areas/*/` — generated by `python3 tools/build_pages.py` (edit content there, then rerun).
- `hvac-repair/` — standalone ad landing page (`assets/css/v2.css`, `assets/js/v2.js`).
- Contact details: `SITE` config at the top of `assets/js/site.js`. Form opens a pre-filled email until `formEndpoint` is set.
- Photos: `assets/work/` (M&H jobs), `assets/media/` (job videos), `assets/stock/` (licensed example photos; credited on the page).
